# 验收检查清单

本文档记录开发过程中发现的、容易出问题的、需要特别关注的检查项。

### P0 - 必须检查

| 检查项 | 来源 | 模块 |
|--------|------|------|
| 日志文件权限问题 | 开发风险 | logging |
| 日志目录不存在时创建 | 开发风险 | logging |
| 时间戳精度（毫秒级） | 设计要求 | logging |
| 跨文件时间戳格式一致 | 设计要求 | logging |
| 流式输出时文件实时写入 | 开发风险 | driver |
| 滚动缓冲区边界（刚好 N 行） | 开发风险 | stream_output |
| Agent 输出中的换行符处理 | 开发风险 | agent_logger |
| Driver Log 分隔符可见性 | 设计要求 | driver_log |

| 检查项 | 来源 | 模块 |
|--------|------|------|
